優れた CLI ツールと同様に、GitHub Copilot CLI には対話に使えるスラッシュコマンドが多数あります。高度な機能、内部情報、追加の構成オプションを利用できます。これまでに `/diff`、`/mcp`、`/skills`、`/agent`、`/pr` などのコマンドを使いました。ここでは、ほかの便利なコマンドをいくつか確認しましょう。

このレッスンでは、次のことを行います。

- `/context` と `/compact` を使い、Copilot の会話コンテキスト管理を確認します。
- `/model` で利用可能なモデルを確認します。
- `/share` でセッションをエクスポートまたは共有する方法を学びます。
- 並列作業、worktree、クラウドエージェントへの委任に使う省略可能なコマンドを確認します。

## シナリオ

CLI の主なワークフローを終えたので、コンテキスト管理、モデルの切り替え、セッション共有、省略可能な [Copilot クラウドエージェント][about-cloud-agent]への委任など、追加機能を確認しましょう。

## Copilot CLI のコンテキストを確認する

大規模または複雑なタスクに取り組むと、モデルの最大コンテキストウィンドウに達することがあります。Copilot CLI は必要に応じて会話を自動的に圧縮します。また、スラッシュコマンドで状態を確認したり、自分で圧縮したりできます。

1. Codespace に戻り、Copilot CLI がまだ開いていない場合は、リポジトリのルートから起動します。
2. 次のコマンドを入力します。

   ```plaintext
   /context
   ```

3. モデル、現在のトークン使用量、システム指示、ツール、メッセージ、空き領域に分割されたコンテキストを確認します。
4. 会話を圧縮します。

   ```plaintext
   /compact
   ```

5. もう一度 `/context` を実行して結果を比較します。会話がすでに短い場合は、大きな違いがないこともあります。

> [!NOTE]
> コンテキストウィンドウが埋まると、Copilot CLI は自動的にコンテキストを圧縮します。圧縮のタイミングを自分で決めたい場合は `/compact` を使います。無関係なタスクに切り替えるときに会話を新しくするには、`/clear` または `/new` を使います。

## モデルを選ぶ

モデルによって得意なことが異なり、開発者によっても好みは異なります。Copilot CLI では、利用可能なモデルを一覧表示し、使用するモデルを選択できます。

1. 次のコマンドを入力します。

   ```plaintext
   /model
   ```

2. 利用可能なモデルと使用状況に関する情報を確認します。
3. 現在のモデルを使い続けるか、別のモデルを選ぶか、<kbd>Esc</kbd> を押して一覧を閉じます。

## セッションを共有する

チームで協力し、学んだことを共有すると、AI ツールをより効果的に使えるようになります。`/share` コマンドを使うと、セッションを Markdown または HTML ファイルにエクスポートしたり、共有リンクを作成したり、GitHub gist を公開したりできます。

1. `/help` を実行し、インストール済みバージョンの `/share` オプションを確認します。
2. セッションを共有する場合は、目的に合った出力先を選択します。たとえば `/share file` はローカルの Markdown ファイルにエクスポートします。
3. エクスポートした内容を、誰かに送信したり公開したりする前に確認します。セッションのエクスポートには、プロンプト、応答、プロジェクトの詳細が含まれる場合があります。

リンクや gist の公開は省略可能です。チームが共有を意図していないリポジトリや会話の内容は公開しないでください。

## 省略可能: 作業の拡張と委任

ワークショップの主要な内容は完了しました。Copilot CLI には、大規模なタスク向けのコマンドもあります。

- `/fleet` は、独立したサブタスクをサブエージェントに分割して並列実行できます。
- `/worktree` は、別のタスク用に分離された Git worktree を作成できます。
- `/delegate` は、タスクを Copilot クラウドエージェントに送り、非同期で処理してプルリクエストを作成できます。

これらのコマンドは追加の worktree やリモート作業を作成することがあるため、省略可能です。試す場合は、まず新しい会話を始めて範囲の明確なタスクを用意し、通常のワークフローで結果をレビューしてください。非同期エージェントの作業を詳しく知りたい場合は、[クラウドエージェントのワークショップ][cloud-workshop]に進みます。

- `/model` で利用可能なモデルを確認しました。
- `/share` でセッションをエクスポートまたは共有する方法を学びました。
